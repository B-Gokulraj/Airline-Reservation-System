# Airline Reservation System

A Java Swing based Airline Reservation System developed using Java and Eclipse IDE.  
This project provides functionalities for both Admin and User modules to manage and book flights efficiently.

---

## Features

### Admin Module
- Admin Login Authentication
- View All Flights
- Update Flight Details
- Cancel Flights
- Manage Flight Information

### User Module
- User Login
- Search Flights
- View Available Flights
- Book Flights
- Reservation Management
- Payment Simulation

---

## How to Run

1. Open project in Eclipse IDE
2. Import the project
3. Run the `MainMenu.java` file
4. Choose Admin or User module
5. Use the Airline Reservation System
